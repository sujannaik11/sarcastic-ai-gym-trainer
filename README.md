# 🏋️ Sarcastic AI Gym Trainer

A funny, sarcastic AI gym trainer built with Python and Ollama. This chatbot roasts your workout excuses, calls out your lack of discipline, and pushes you to get back on track with humorous, motivational responses.

## ✨ Features

- 😂 Sarcastic and humorous gym trainer personality
- 💪 Motivational responses to workout excuses
- 🧠 Maintains conversation history
- 🖥️ Runs locally using Ollama
- 🤖 Powered by the Qwen 3.5 0.8B language model
- 🎯 Custom AI personality through system prompts

## 🛠️ Tech Stack

- Python
- Ollama
- Qwen 3.5 0.8B
- Ollama Python library

## 🚀 How to Run

1. Install Python and Ollama.
2. Download the model using `ollama pull qwen3.5:0.8b`.
3. Install the dependency using `pip install ollama`.
4. Run the application using `python prompt2.py`.

## 🎯 Project Goal

To build a locally running AI trainer that combines humor, sarcasm, and motivation to encourage workout consistency and discipline.
